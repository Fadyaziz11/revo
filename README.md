# WatchNow - Complete Arabic Streaming Platform & Admin Dashboard
منصة البث المباشر والأفلام والمسلسلات العربية المتكاملة مع لوحة تحكم إدارية شاملة

---

## 🌟 نظرة عامة (Overview)
تم بناء منصة **WatchNow** كمنصة بث رقمي عربية متكاملة عالية الأداء مستوحاة ومطابقة بدقة للتصميم المرجعي المرفق، متوافقة تماماً مع معايير العرض RTL ومتجاوبة مع كافة الشاشات (الهواتف، الأجهزة اللوحية، وشاشات سطح المكتب).

---

## 🚀 الميزات الرئيسية (Key Features)

### 1. الواجهة العامة والمظهر (Visual Design & Public Experience)
- **تطابق مرئي كامل**: تصميم داكن أسود وكحلي داكن (`#0b0e17`) مع لمسات حمراء أنيقة (`#e50914`).
- **دعم كامل للغة العربية (RTL First)** وخط عربي أنيق (Cairo) من Google Fonts.
- **بانر رئيسي سينمائي (Hero Banner)**: لفيلم *John Wick 4* مع تفاصيل الفئات والتقييم وأزرار المشاهدة والإضافة للمفضلة ومؤشرات الشرائح التفاعلية.
- **شريط الفلاتر السريعة الأفقية (7 بطاقات)**: أفلام، مسلسلات، قنوات مباشرة، رياضة، أفلام جديدة، الأكثر مشاهدة، وجودة عالية HD.
- **صفوف المحتوى المتجاوبة**:
  - صف **أحدث الأفلام** (Dune, The Batman, Top Gun, Avengers, Interstellar, Joker).
  - صف **أحدث المسلسلات** بالبوسترات العريضة Landscape (Game of Thrones, Breaking Bad, Money Heist, Stranger Things, The Last of Us, Vikings).
  - صف **قنوات البث المباشر (كرة القدم)** (beIN SPORTS 1 & 2, SSC 1, Sky Sports, TNT, ON Time).
- **الشريط الجانبي الأيمن المتطابق (Right Sidebar)**:
  - صندوق **مباريات اليوم - بث مباشر** مع الكلاسيكو (ريال مدريد vs برشلونة) بنتيجة حية ومؤشر مباشر نابض.
  - قائمة البطولات والدوريات الرسمية (دوري أبطال أوروبا، الدوري الإنجليزي، الدوري الإسباني، الدوري الإيطالي، الدوري المصري).
  - قائمة القنوات الفضائية مع شارات البث المباشر.
  - بطاقة العرض الترويجي لأهم المباريات بجودة عالية وبدون تقطيع.

### 2. مشغل الفيديو المتقدم (Advanced Video Player)
- يدعم تدفقات **HLS (.m3u8)** التكيفية عبر مكتبة `hls.js` ومشغلات **HTML5 (MP4)**.
- واجهة تحكم مخصصة بالكامل:
  - تشغيل / إيقاف مؤقت، شريط تقديم زمني تفاعلي، عداد وقت، تحكم بالصوت مع كتم، ملء الشاشة.
  - قائمة تبديل الجودة والسيرفرات البديلة (1080p, 720p, 480p).
  - نظام معالجة الأخطاء الذكي: تسجيل تلقائي لأخطاء الشبكة والبث مع واجهة استرداد واقتراح سيرفرات بديلة.
  - توثيق مشاهدات حقيقي عند المشاهدة المستمرة لأكثر من 10 ثوانٍ لمنع التكرار الوهمي.

### 3. صفحات المحتوى المخصصة
- **صفحة الأفلام (`/movies`)**: فلترة حسب التصنيف، الجودة، والترتيب حسب الأحدث أو الأعلى تقييماً أو الأكثر مشاهدة.
- **صفحة المسلسلات (`/series`)**: استعراض المسلسلات مع نافذة اختيار المواسم والحلقات والتنقل السلس.
- **صفحة القنوات التلفزيونية (`/live-tv`)**: تصنيف القنوات (رياضية، ترفيهية، إخبارية) ومؤشر فحص الإشارة.
- **صفحة المباريات والرياضة (`/sports`)**: تتبع نتائج المباريات الحية والمنتهية والقادمة مع أسماء المعلقين والملاعب.
- **البحث الشامل والمباشر (Universal Live Search)**: بحث فوري عبر كافة أنواع المحتوى مع فلاتر سريعة.
- **المفضلة وسجل المشاهدة (Watchlist & History)**: حفظ الأعمال ومتابعة شريط التقدم الزمني.

### 4. لوحة التحكم الإدارية الآمنة (Admin Dashboard at `/admin`)
- **لوحة الإحصائيات العامة (Overview)**: إجمالي الأفلام، المسلسلات، الحلقات، القنوات، والمباريات والمشاهدات.
- **إدارة الأفلام (CRUD)**: إضافة، تعديل، حذف، تغيير روابط سيرفرات البث، تعديل الملصقات والخلفيات.
- **إدارة المسلسلات والحلقات**: التحكم بالمواسم، إضافة حلقات جديدة، وتفادي الحلقات اليتيمة.
- **إدارة القنوات الفضائية**: ضبط روابط البث وفحص حالة الاتصال.
- **إدارة المباريات**: تعديل الفرق، النتائج، والتوقيت، وحالة المباراة.
- **تخصيص الهوية والموقع**: اسم المنصة، الشعار، ألوان الموقع، بيانات التواصل، وعناوين الـ SEO.
- **إدارة المستخدمين والصلاحيات**: منع المستخدمين العاديين من ترقية أنفسهم لمشرفين.
- **التقارير والإحصائيات وتصدير CSV**: تنزيل سجلات المشاهدات بصيغة CSV.
- **سجل العمليات الإدارية (Audit Trail)**: توثيق غير قابل للتعديل لكافة الإجراءات.
- **إعدادات وموصل Firebase**: التبديل السلس بين وضع المعاينة المحلي وCloud Firestore مع فحص الاتصال التلقائي.

## 🗄️ معمارية قاعدة البيانات وقواعد الأمان (Database & Security)
- **`firebase-blueprint.json`**: مخطط الكيانات والمجموعات.
- **`firestore.rules`**: قواعد أمان مشددة تعتمد على مبدأ Zero-Trust:
  - حظر عام افتراضي `allow read, write: if false;`.
  - القراءة العامة مقتصرة فقط على المحتوى المنشور `resource.data.published == true`.
  - حماية كافة عمليات التعديل والكتابة بحسابات المشرفين المعتمدين (`isAdmin()`).
  - سجل العمليات الإدارية `adminAuditLogs` للقراءة والإنشاء فقط لمنع التلاعب بالسجلات.
- **`src/services/storage.ts`**: نظام تخزين هجين يضمن استمرار البيانات وتحديث الواجهة فورياً.
